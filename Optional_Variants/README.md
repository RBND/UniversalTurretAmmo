# Optional Variants

This directory contains optional configuration variants for **Universal Turret Ammo**.

## Ballistics-Only
Excludes all Robotic Turret ammunition, keeping automated turrets strictly to traditional firearm ammunition:
- **SMG Auto Turret**: Uses 9mm (Ball, AP, HP) and .44 Magnum (Ball, AP, HP).
- **Shotgun Auto Turret**: Uses Shotgun Shells, AP Slugs, and Breaching Slugs.
- **M60 Auto Turret**: Uses 7.62mm (Ball, AP, HP).

### How to Apply a Variant
1. Copy the `Config/` folder from `Optional_Variants/Ballistics-Only/`.
2. Paste it into `UniversalTurretAmmo/`, replacing the files in `UniversalTurretAmmo/Config/`.
3. Restart your game or server.
